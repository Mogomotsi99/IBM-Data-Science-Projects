# IBM-Data-Science-Projects
Welcome to my comprehensive data science portfolio. This repository serves as an operational archive compiling all core projects, advanced laboratory pipelines, and statistical methodologies executed throughout the **IBM Data Science Professional Certificate** curriculum. 

The portfolio showcases a complete modern data science lifecycle: from automated web scraping and REST API data engineering to relational SQL query optimisation, dynamic geospatial processing, production-ready interactive dashboards, and hyperparameter-tuned machine learning classification frameworks.

## Core Skills & Technical Stack Demonstrated
* **Languages:** Python (Pandas, NumPy, Requests, BeautifulSoup, Matplotlib, Seaborn)
* **Databases & Relational Analytics:** SQL, SQLite,
* **Geospatial & Interactive Visual Analytics:** Folium Mapping Engine, Plotly, Plotly Dash Web Framework
* **Predictive Modeling & Machine Learning:** Scikit-Learn (Supervised Classification, Feature Standardisation, Hyperparameter Optimisation via `GridSearchCV`, Model Selection and Evaluation)
